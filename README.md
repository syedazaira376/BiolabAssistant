# BioLab Assistant

## Overview

BioLab Assistant is an AI-powered educational web application developed for biotechnology, microbiology, and life science students. It provides interactive learning resources on laboratory techniques, biosafety, laboratory equipment, and experimental protocols through an intelligent AI Lab Assistant.

---

## Problem Statement

Biotechnology students often rely on multiple books and online resources to understand laboratory techniques and experimental procedures. BioLab Assistant brings all essential laboratory learning resources into one platform, making learning easier, faster, and more interactive.

## AI Feature

The application includes an AI Lab Assistant powered by Google's Gemini model. Users can ask questions related to laboratory techniques, biotechnology experiments, biosafety, laboratory equipment, and troubleshooting. The assistant provides structured, educational, and evidence-based responses to support practical and theoretical learning.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY.git
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add your Gemini API key:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application:

```bash
npm run dev
```
